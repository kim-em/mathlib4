FINITE FREE STAM INEQUALITY — Prove n=4 case explicitly

=== GOAL ===

Prove the single sorry: finite_free_stam_inequality for all n ≥ 2.
  invPhi (boxplus n p q) ≥ invPhi p + invPhi q

=== STRATEGY: Complete n=4 case, then case-split n ≤ 4 ===

We have n=2 and n=3 proven. Proving n=4 would give us n ≤ 4.

For CENTERED degree-4 monic polynomial: p = X⁴ + aX² + bX + c
Roots: λ₁, λ₂, λ₃, λ₄ with λ₁+λ₂+λ₃+λ₄ = 0 (centered).

Power sums:
  e₁ = 0 (centered)
  e₂ = -a (elementary sym poly, with sign convention)
  p₂ = Σλᵢ² = -2a
  p₃ = Σλᵢ³ = -3b  (by Newton's identity: p₃ = -3e₃ + ... since e₁ = 0)
  p₄ = Σλᵢ⁴ = 2a² - 4c  (by Newton's identity)

Score at root λᵢ:
  Sᵢ = Σ_{j≠i} 1/(λᵢ - λⱼ) = p''(λᵢ)/(2p'(λᵢ))
  p'(x) = 4x³ + 2ax + b
  p''(x) = 12x² + 2a
  Sᵢ = (12λᵢ² + 2a) / (2(4λᵢ³ + 2aλᵢ + b)) = (6λᵢ² + a) / (4λᵢ³ + 2aλᵢ + b)

Phi = Σᵢ Sᵢ² = Σᵢ (6λᵢ² + a)² / (4λᵢ³ + 2aλᵢ + b)²

Under boxplus of centered quartics:
  (p ⊞₄ q) is centered with coefficients:
  a_{p⊞q} = aₚ + a_q  (by boxplus_centered_coeff_add or cumulant additivity)
  b_{p⊞q} = bₚ + b_q  (by cumulant additivity of κ₃)
  c_{p⊞q} = cₚ + c_q + (aₚ·a_q)/6  ... or similar correction from cumulant to coefficient

Wait — the coefficients are NOT simply additive for k ≥ 3 (only cumulants are).
The cumulants for degree 4 are:
  κ₂ ∝ a (coefficient of X²)
  κ₃ ∝ b (coefficient of X)
  κ₄ = function(a, c) — involves a correction from a²

So under boxplus:
  κ₂(p⊞q) = κ₂(p) + κ₂(q)  →  a_{p⊞q} = aₚ + a_q
  κ₃(p⊞q) = κ₃(p) + κ₃(q)  →  b_{p⊞q} = bₚ + b_q
  κ₄(p⊞q) = κ₄(p) + κ₄(q)  →  c_{p⊞q} = cₚ + c_q + f(aₚ, a_q)

The EXACT formula for c_{p⊞q} in terms of cₚ, c_q, aₚ, a_q comes from
the cumulant-to-coefficient relation (scaled_coeff_boxplus in context).
