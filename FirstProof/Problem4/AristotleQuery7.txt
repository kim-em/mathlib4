FINITE FREE STAM INEQUALITY — Full n=4 Case and n=5 Exploration

This is a continuation of 6 previous Aristotle queries on the Finite Free Stam Inequality
(Problem 4 from arXiv:2602.05192, the "First Proof" benchmark).

The main conjecture: for monic real-rooted degree-n polynomials p, q with distinct roots,
  1/Phi_n(p ⊞_n q) >= 1/Phi_n(p) + 1/Phi_n(q)
where Phi_n(p) = sum_i (sum_{j!=i} 1/(lambda_i - lambda_j))^2
and ⊞_n is finite free additive convolution.

=== KEY STRUCTURAL INSIGHT ===

Finite free cumulants kappa_k are ADDITIVE under ⊞_n:
  kappa_k(p ⊞_n q) = kappa_k(p) + kappa_k(q)

This is proven for all n (in Query 3). It means: if we can express 1/Phi_n as a
SUPERADDITIVE function f of the cumulants, the main inequality follows immediately.

The L-Q PATTERN observed so far:
  n=2: 1/Phi_2 = -kappa_2  (linear, hence additive)
  n=3: 1/Phi_3 = (2/9)(-kappa_2) - (3/2)(kappa_3^2 / kappa_2^2)
       Linear in -kappa_2 minus a CONVEX quotient in kappa_3
  n=4 sym: 1/Phi_4 = (2/3)(-kappa_2) - (4/3)(kappa_4^2 / (-kappa_2 * (kappa_2^2 + kappa_4)))
       Linear in -kappa_2 minus a CONVEX quotient in kappa_4

Pattern: 1/Phi_n = c_n * (-kappa_2) - Q_n(kappa_3, ..., kappa_n, kappa_2)
where Q_n is convex in (kappa_3,...,kappa_n), making f superadditive.

Cumulant formulas for quartics (also proven in Query 6):
  kappa_2 = A/12, kappa_3 = B/24, kappa_4 = C/24 - A^2/288

=== GOAL A (PRIMARY): Full n=4 Case ===

Prove the Stam inequality for GENERAL centered quartics (not just symmetric):

For a centered quartic p(x) = x^4 + Ax^2 + Bx + C with 4 distinct real roots:
  - kappa_2(p) = A/12
  - kappa_3(p) = B/24
  - kappa_4(p) = C/24 - A^2/288

Step 1: Compute 1/Phi_4 as a function f(kappa_2, kappa_3, kappa_4).

Use the derivative form: Phi_4(p) = sum_i ((6 r_i^2 + A) / (4 r_i^3 + 2A r_i + B))^2
where r_1,...,r_4 are roots summing to 0.

The result should be a rational function of A, B, C (equivalently kappa_2, kappa_3, kappa_4).

IMPORTANT OBSERVATIONS:
- When B=0 (kappa_3=0), the formula MUST reduce to the proven symmetric case.
- Phi_4 is EVEN in B: if roots are {r_i}, replacing by {-r_i} negates B but preserves Phi.
  So Phi_4(A,B,C) = Phi_4(A,-B,C), meaning B appears only in even powers.
- Therefore 1/Phi_4(kappa_2, kappa_3, kappa_4) should have kappa_3 appearing only in even powers.

Step 2: Prove f(kappa_2, kappa_3, kappa_4) is superadditive.

The symmetric case proof used:
  (a) Linear term additive
  (b) Cauchy-Schwarz: sum of ratios >= ratio of sums
  (c) Denominator superadditivity

For the general case, try the same L-Q decomposition.

Alternatively, try a PERTURBATION approach:
  - For kappa_3 = 0 (symmetric), the inequality is proven.
  - d/d(kappa_3) [1/Phi_4] at kappa_3=0 equals 0 (by the B-parity observation).
  - If d^2/d(kappa_3)^2 [1/Phi_4] <= 0 (concavity in kappa_3), then the perturbation
    can only help the inequality.

Suggested theorem statement:

theorem stam_inequality_n4_general (A1 B1 C1 A2 B2 C2 : R)
    (h_roots1 : -- p1 = X^4 + C A1 * X^2 + C B1 * X + C C1 has 4 distinct real roots)
    (h_roots2 : -- p2 has 4 distinct real roots)
    (h_roots3 : -- boxplus 4 p1 p2 has 4 distinct real roots) :
    invPhi (boxplus 4 p1 p2) >= invPhi p1 + invPhi p2

=== GOAL B (SECONDARY): n=5 Symmetric Case ===

Explore degree 5 to test whether the L-Q pattern continues.

For a SYMMETRIC centered quintic: p(x) = x^5 + Ax^3 + Cx (odd symmetry, kappa_3=kappa_5=0).
This has roots {0, +-r1, +-r2} for some r1, r2 > 0.

Step 1: Compute Phi_5 for this polynomial.
Use p'(x) = 5x^4 + 3Ax^2 + C, p''(x) = 20x^3 + 6Ax.
Phi_5 = sum_i (p''(r_i) / (2 p'(r_i)))^2 at the 5 roots.

Step 2: Express 1/Phi_5 in terms of kappa_2 and kappa_4.
For the symmetric quintic: kappa_2 = A/20 (since binomial(5,2)=10, and kappa_2 = coeff/binomial),
kappa_4 = C/120 - A^2/(20*... ) (compute from the hat transform).

If yes, prove superadditivity using the same Cauchy-Schwarz pattern.

Even if you cannot prove superadditivity, STATING THE FORMULA is valuable.

=== SCALING NORMALIZATION HINT ===

By Phi_scaleRoots (proven), Phi scales by 1/c^2 under root scaling, so 1/Phi scales by c^2.
Cumulants scale as kappa_k ~ c^k. So we can normalize kappa_2 = -1 (i.e. set c so that
-kappa_2 = 1), prove superadditivity in the reduced parameter space (kappa_3, kappa_4),
then lift back by scaling. This reduces the number of free parameters.

=== B-PARITY LEMMA ===

A useful standalone lemma to prove first:

lemma Phi_neg_roots (n : N) (r : Fin n -> R) :
    phi n r = phi n (fun i => -r i)

This formalizes the observation that negating all roots preserves Phi, which means
for centered quartics, Phi(A,B,C) = Phi(A,-B,C), so B (hence kappa_3) appears only
in even powers in the Phi formula.
