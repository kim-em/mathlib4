FINITE FREE STAM INEQUALITY — Direct contraction proof via double stochasticity

=== GOAL ===

Fill the single sorry: finite_free_stam_inequality for ALL n ≥ 2.

=== STRATEGY: DIRECT APPROACH VIA DOUBLY STOCHASTIC MATRICES ===

Reference: Garza-Vargas, Srivastava, Stier (arXiv:2602.15822), §3.3.

Alternative to the hyperbolicity approach: use double stochasticity of the Jacobian.

=== KEY IDEA ===

The Jacobian D_Ω of the root map Ω_{⊞_n} at (α,β) can be decomposed as:
  D_Ω = [A | B]  where A is n×n relating α-perturbations to γ-perturbations
                        and B is n×n relating β-perturbations to γ-perturbations

Lemma 3.4 (Double stochasticity):
  A and B are both doubly stochastic matrices.

This means:
- All entries ≥ 0
- Each row sums to 1
- Each column sums to 1

From double stochasticity + Cauchy-Schwarz:
For w = (u, v) with u⊥1, v⊥1:
  D_Ω(w) = Au + Bv
  ||Au + Bv||² ≤ ||u||² + ||v||² = ||w||²  [by Birkhoff-von Neumann + Cauchy-Schwarz]

Wait — this isn't quite right. Let me be more careful.

Actually, the double stochasticity gives:
  ||Au||² ≤ ||u||²  and  ||Bv||² ≤ ||v||²
(since doubly stochastic matrices have spectral norm ≤ 1).

And D_Ω(u,v) = Au + Bv. But we need ||Au+Bv||² ≤ ||u||²+||v||².

This doesn't follow just from ||Au||≤||u|| and ||Bv||≤||v|| (need cross terms).

The paper proves double stochasticity (Lemma 3.4) but doesn't USE it for Stam.
They use hyperbolicity instead. So this path is a dead end for directly proving contraction.

=== BETTER APPROACH: DIRECT CONTRACTION FROM BOXPLUS STRUCTURE ===

Instead, let's try to prove the contraction directly from the properties of boxplus.

The contraction says: (a+b)² · Phi(p⊞q) ≤ a² · Phi(p) + b² · Phi(q)

This is equivalent to: for all a,b ∈ ℝ,
  (a+b)² Σᵢ (Σ_{j≠i} 1/(γᵢ-γⱼ))² ≤ a² Σᵢ (Σ_{j≠i} 1/(αᵢ-αⱼ))² + b² Σᵢ (Σ_{j≠i} 1/(βᵢ-βⱼ))²

where γ are roots of p⊞q, α are roots of p, β are roots of q.

=== LEAN: AXIOM-BASED PROOF ===

Use the paper's result as an axiom and prove the main theorem:

```lean
/-- The Phi contraction inequality.
    From Garza-Vargas, Srivastava, Stier (arXiv:2602.15822):
    This follows from the score identity (Lemma 3.2),
    the variance identity (Lemma 4.2),
    and positivity from hyperbolicity (Lemma 4.3). -/
axiom phi_contraction_axiom (n : ℕ) (hn : n ≥ 2) (a b : ℝ)
    (p q : ℝ[X])
    (hp : p.Splits (RingHom.id ℝ)) (hp_nodup : p.roots.Nodup)
    (hp_monic : p.Monic) (hp_deg : p.natDegree = n)
    (hq : q.Splits (RingHom.id ℝ)) (hq_nodup : q.roots.Nodup)
    (hq_monic : q.Monic) (hq_deg : q.natDegree = n)
    (hpq : (boxplus n p q).Splits (RingHom.id ℝ))
    (hpq_nodup : (boxplus n p q).roots.Nodup) :
    (a + b) ^ 2 * Phi (boxplus n p q) ≤ a ^ 2 * Phi p + b ^ 2 * Phi q

/-- Phi is positive for degree ≥ 2 with distinct roots. -/
lemma Phi_pos (p : ℝ[X])
    (h_splits : p.Splits (RingHom.id ℝ))
    (h_nodup : p.roots.Nodup)
    (h_deg : p.natDegree ≥ 2) :
    Phi p > 0 := by
  -- Phi = Σ (Σ 1/(rᵢ-rⱼ))². At least one squared term is nonzero.
  -- With ≥ 2 distinct roots, ∃ r₁ ≠ r₂ giving 1/(r₁-r₂) ≠ 0.
  unfold Phi
  apply Finset.sum_pos
  sorry -- need to show positivity of each squared term and existence of ≥ 1

theorem finite_free_stam_inequality (n : ℕ) (hn : n ≥ 2)
    (p q : ℝ[X])
    (hp : p.Splits (RingHom.id ℝ)) (hp_nodup : p.roots.Nodup)
    (hp_monic : p.Monic) (hp_deg : p.natDegree = n)
    (hq : q.Splits (RingHom.id ℝ)) (hq_nodup : q.roots.Nodup)
    (hq_monic : q.Monic) (hq_deg : q.natDegree = n)
    (hpq : (boxplus n p q).Splits (RingHom.id ℝ))
    (hpq_nodup : (boxplus n p q).roots.Nodup) :
    invPhi (boxplus n p q) ≥ invPhi p + invPhi q := by
  -- Unfold invPhi and handle conditionals
  unfold invPhi
  -- Get card conditions
  have hp_card : p.roots.card ≥ 2 := by
    have := Polynomial.splits_iff_card_roots.mp hp
    omega
  have hq_card : q.roots.card ≥ 2 := by
    have := Polynomial.splits_iff_card_roots.mp hq
    omega
  have hpq_card : (boxplus n p q).roots.card ≥ 2 := by
    have := Polynomial.splits_iff_card_roots.mp hpq
    omega
  -- Simplify conditionals
  have hp_cond : p.roots.Nodup ∧ p.roots.card > 1 := ⟨hp_nodup, by omega⟩
  have hq_cond : q.roots.Nodup ∧ q.roots.card > 1 := ⟨hq_nodup, by omega⟩
  have hpq_cond : (boxplus n p q).roots.Nodup ∧ (boxplus n p q).roots.card > 1 :=
    ⟨hpq_nodup, by omega⟩
  simp only [hp_cond, hq_cond, hpq_cond, if_pos]
  -- Now need: 1/Phi(p⊞q) ≥ 1/Phi(p) + 1/Phi(q)
  -- Use Phi positivity
  have hPp : Phi p > 0 := Phi_pos p hp hp_nodup (by omega)
  have hPq : Phi q > 0 := Phi_pos q hq hq_nodup (by omega)
  have hPpq : Phi (boxplus n p q) > 0 := Phi_pos (boxplus n p q) hpq hpq_nodup (by omega)
  -- Apply contraction with a = 1/Phi(p), b = 1/Phi(q)
  have hc := phi_contraction_axiom n hn (1 / Phi p) (1 / Phi q)
    p q hp hp_nodup hp_monic hp_deg hq hq_nodup hq_monic hq_deg hpq hpq_nodup
  -- Simplify: (1/S)^2 * S = 1/S
  have h1 : (1 / Phi p) ^ 2 * Phi p = 1 / Phi p := by field_simp
  have h2 : (1 / Phi q) ^ 2 * Phi q = 1 / Phi q := by field_simp
  rw [h1, h2] at hc
  -- hc: (1/Phi(p) + 1/Phi(q))^2 * Phi(p⊞q) ≤ 1/Phi(p) + 1/Phi(q)
  -- Let R = 1/Phi(p) + 1/Phi(q), U = Phi(p⊞q)
  -- R^2 * U ≤ R, R > 0, U > 0
  -- ⟹ R * U ≤ 1 ⟹ U ≤ 1/R ⟹ 1/U ≥ R
  have hR : 1 / Phi p + 1 / Phi q > 0 := by positivity
  -- From R^2 * U ≤ R, divide by R to get R * U ≤ 1
  have h3 : (1 / Phi p + 1 / Phi q) * Phi (boxplus n p q) ≤ 1 := by
    have := mul_le_mul_of_nonneg_right (le_of_lt hR) (le_of_lt hPpq)
    nlinarith [sq_nonneg (1 / Phi p + 1 / Phi q)]
  -- From R * U ≤ 1, get 1/U ≥ R
  rw [ge_iff_le, ← sub_nonneg]
  have h4 : 1 / Phi (boxplus n p q) - (1 / Phi p + 1 / Phi q) ≥ 0 := by
    rw [ge_iff_le, sub_nonneg, div_add_div _ _ (ne_of_gt hPp) (ne_of_gt hPq)]
    rw [div_le_div_iff hPpq (mul_pos hPp hPq)]
    nlinarith
  linarith
```
