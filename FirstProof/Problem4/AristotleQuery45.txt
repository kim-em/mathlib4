SUBSTITUTION APPROACH:

  Also α < 1/6 (so x < 1/4) and β < 1/12 (so y > 0).

Then:
  Z = t²(1/12+α) + (1-t)²(1/12-β) + t(1-t)/6
    = 1/12 + t²α - (1-t)²β + [t² + (1-t)² - 1 + 2t(1-t)]/12 · 0

  Actually, let's compute more carefully:
  Z = t²(1/12+α) + (1-t)²(1/12-β) + t(1-t)/6
    = t²/12 + t²α + (1-t)²/12 - (1-t)²β + t(1-t)/6
    = [t² + (1-t)² + 2t(1-t)]/12 + t²α - (1-t)²β
    = 1/12 + t²α - (1-t)²β

  So Z < 1/12 iff t²α < (1-t)²β.
  Since t < 1/2: (1-t) > t, so (1-t)² > t².
  And α > β, so t²α > t²β.
  Need: t²α < (1-t)²β, i.e., (t/(1-t))² < β/α.

  Since α > β: β/α < 1, so (t/(1-t))² < 1, i.e., t < 1/2. ✓ (already known)

Now the inequality becomes:
  f_aux(1/12 + t²α - (1-t)²β) ≥ t·f_aux(1/12+α) + (1-t)·f_aux(1/12-β)

Let δ = t²α - (1-t)²β (which is negative in Case 4).

  f_aux''(1/12) = -64/(12·1/12+1)³ = -64/8 = -8 (from f_aux_second_deriv)

So f_aux(1/12+δ) ≈ f_aux(1/12) - 4δ²

  = f_aux(1/12) - 4(tα² + (1-t)β²)

We need: -4δ² ≥ -4(tα² + (1-t)β²)
i.e., δ² ≤ tα² + (1-t)β²
i.e., (t²α - (1-t)²β)² ≤ tα² + (1-t)β²

  If Z ≥ W, done. But in Case 4, Z < W.
  So f_aux(Z) ≥ f_aux(W) + f_aux'(W)·(Z - W)
