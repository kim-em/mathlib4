FINITE FREE STAM INEQUALITY — Phi contraction implies Stam (Cauchy-Schwarz step)

=== GOAL ===

Fill the single sorry: finite_free_stam_inequality for ALL n ≥ 2.

=== STRATEGY: CAUCHY-SCHWARZ FROM CONTRACTION ===

Reference: Garza-Vargas, Srivastava, Stier (arXiv:2602.15822), proof of Theorem 1.4.

The proof has TWO layers:

LAYER 1: State the "Phi contraction" as a lemma (with sorry).
For all a, b ∈ ℝ and polynomials p, q satisfying the usual hypotheses:
  (a + b)^2 * Phi(boxplus n p q) ≤ a^2 * Phi(p) + b^2 * Phi(q)

This says: the score norm squared contracts under boxplus. It is the heart of the proof.

LAYER 2: Derive Stam from contraction (pure algebra).
Given contraction, choose a = invPhi(p), b = invPhi(q):
  (invPhi(p) + invPhi(q))^2 * Phi(boxplus n p q) ≤ invPhi(p)^2 * Phi(p) + invPhi(q)^2 * Phi(q)
  = invPhi(p) + invPhi(q)

Therefore: Phi(boxplus n p q) ≤ 1/(invPhi(p) + invPhi(q))
i.e.: invPhi(boxplus n p q) ≥ invPhi(p) + invPhi(q)

=== Phi POSITIVITY ===

We need Phi(p) > 0 for real-rooted degree ≥ 2 polynomials with distinct roots.
This follows because Phi is a sum of squares: Phi p = Σ (Σ 1/(rᵢ-rⱼ))²,
and for degree ≥ 2 with distinct roots, at least one term is nonzero.

    For all a, b ∈ ℝ, the squared score norm satisfies a contraction bound. -/
lemma phi_contraction (n : ℕ) (hn : n ≥ 2) (a b : ℝ)
    (p q : ℝ[X])

    (a + b) ^ 2 * Phi (boxplus n p q) ≤ a ^ 2 * Phi p + b ^ 2 * Phi q := by

/-- The main theorem follows from the contraction by Cauchy-Schwarz. -/
theorem finite_free_stam_inequality (n : ℕ) (hn : n ≥ 2)
    (p q : ℝ[X])
    (hp : p.Splits (RingHom.id ℝ)) (hp_nodup : p.roots.Nodup)
    (hp_monic : p.Monic) (hp_deg : p.natDegree = n)
    (hq : q.Splits (RingHom.id ℝ)) (hq_nodup : q.roots.Nodup)
    (hq_monic : q.Monic) (hq_deg : q.natDegree = n)
    (hpq : (boxplus n p q).Splits (RingHom.id ℝ))
    (hpq_nodup : (boxplus n p q).roots.Nodup) :
    invPhi (boxplus n p q) ≥ invPhi p + invPhi q := by
  -- Step 1: Handle the invPhi definition (conditional on Nodup and card > 1)
  unfold invPhi
  -- Step 2: Get Phi positivity
  have hp_card : p.roots.card ≥ 2 := by
    rw [Polynomial.splits_iff_card_roots.mp hp]; omega
  have hq_card : q.roots.card ≥ 2 := by
    rw [Polynomial.splits_iff_card_roots.mp hq]; omega
  have hpq_card : (boxplus n p q).roots.card ≥ 2 := by
    rw [Polynomial.splits_iff_card_roots.mp hpq]; omega
  have hPhip := Phi_pos p hp hp_nodup hp_card
  have hPhiq := Phi_pos q hq hq_nodup hq_card
  have hPhipq := Phi_pos (boxplus n p q) hpq hpq_nodup hpq_card
  -- Step 3: Apply contraction with a = 1/Phi(p), b = 1/Phi(q)
  have hc := phi_contraction n hn (1 / Phi p) (1 / Phi q) p q
    hp hp_nodup hp_monic hp_deg hq hq_nodup hq_monic hq_deg hpq hpq_nodup
  -- Step 4: Simplify
  -- hc says: (1/Phi(p) + 1/Phi(q))^2 * Phi(p⊞q) ≤ (1/Phi(p))^2 * Phi(p) + (1/Phi(q))^2 * Phi(q)
  -- RHS = 1/Phi(p) + 1/Phi(q)
  -- So: (1/Phi(p) + 1/Phi(q))^2 * Phi(p⊞q) ≤ 1/Phi(p) + 1/Phi(q)
  -- Dividing by (1/Phi(p) + 1/Phi(q)) > 0:
  -- (1/Phi(p) + 1/Phi(q)) * Phi(p⊞q) ≤ 1
  -- So: Phi(p⊞q) ≤ 1/(1/Phi(p) + 1/Phi(q))
  -- i.e.: 1/Phi(p⊞q) ≥ 1/Phi(p) + 1/Phi(q)
  -- Use field_simp, nlinarith, or direct arithmetic
  sorry

=== ARITHMETIC HINT ===

The key algebraic manipulation is:
Given S > 0, T > 0, U > 0 and (a+b)^2 * U ≤ a^2 * S + b^2 * T for all a,b:
Choose a = 1/S, b = 1/T:
  (1/S + 1/T)^2 * U ≤ 1/S^2 * S + 1/T^2 * T = 1/S + 1/T
Let R = 1/S + 1/T > 0:
  R^2 * U ≤ R
  R * U ≤ 1
  U ≤ 1/R
  1/U ≥ R = 1/S + 1/T

Use nlinarith with positivity hints, or field_simp + nlinarith.
