# Source PDFs

These PDFs are not tracked in git. Download them with:

```bash
# Marcus, Spielman, Srivastava — "Finite Free Convolutions of Polynomials" (37pp)
curl -L -o marcus-spielman-srivastava-finite-free-convolutions.pdf https://arxiv.org/pdf/1504.00350

# Marcus — "Polynomial convolutions and (finite) free probability" (44pp)
curl -L -o marcus-polynomial-convolutions-finite-free.pdf https://arxiv.org/pdf/2108.07054

# Mingo & Speicher — "Free Probability and Random Matrices" (2017, 336pp)
curl -L -o mingo-speicher-free-probability-random-matrices.pdf https://mast.queensu.ca/~mingo/mingo_speicher_2017.pdf
```

Use `qpdf --split-pages <file>.pdf pages/<file>-page.pdf` to split into individual pages for reading.
