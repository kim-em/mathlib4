FINITE FREE STAM INEQUALITY — Variance additivity and score vector infrastructure

=== GOAL ===

Fill the single sorry: finite_free_stam_inequality for ALL n ≥ 2.

=== STRATEGY: ROOT-LEVEL INFRASTRUCTURE ===

Reference: Garza-Vargas, Srivastava, Stier (arXiv:2602.15822), §2.

Build the foundational infrastructure for the general-n proof via score vectors.

=== KEY DEFINITIONS ===

1. SCORE VECTOR: For a monic polynomial p with distinct roots r₁,...,rₙ:
   score(p, rᵢ) = Σ_{j≠i} 1/(rᵢ - rⱼ)

   Note: This is already implicit in Phi:
   Phi p = Σᵢ score(p, rᵢ)²

2. SCORE ORTHOGONALITY: Σᵢ score(p, rᵢ) = 0
   Proof: Σᵢ Σ_{j≠i} 1/(rᵢ-rⱼ) = Σ_{i<j} (1/(rᵢ-rⱼ) + 1/(rⱼ-rᵢ)) = 0
   Each pair cancels!

3. VARIANCE of roots: var(p) = (1/n) Σᵢ rᵢ² - ((1/n) Σᵢ rᵢ)²

4. VARIANCE ADDITIVITY for boxplus (Proposition 2.7 in the paper):
   var(boxplus n p q) = var(p) + var(q)
   This is a fundamental property of finite free convolution.

def root_variance (p : ℝ[X]) : ℝ :=
  let n := p.roots.card
  if n = 0 then 0

    let roots := p.roots.toFinset

=== WHY THIS MATTERS ===

Variance additivity is the KEY ingredient in the proof of the contraction inequality.
The contraction is proved by differentiating variance additivity twice:
  var(Ω(α+tu, β+tv)) = var(α+tu) + var(β+tv)  for all t
  ⟹ ||D_Ω(w)||² + Σᵢ γᵢ·Hᵢ(w,w) = ||w||²  (second derivative at t=0)
