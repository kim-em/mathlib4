FINITE FREE STAM INEQUALITY — Full proof assembly via contraction

=== GOAL ===

Fill the single sorry: finite_free_stam_inequality for ALL n ≥ 2.

=== STRATEGY: ASSEMBLE THE FULL PROOF ===

Reference: Garza-Vargas, Srivastava, Stier (arXiv:2602.15822).

This query assembles the complete proof chain. The key insight from the paper is
that the Stam inequality follows from a CONTRACTION property:

  (a+b)² · Phi(p⊞q) ≤ a² · Phi(p) + b² · Phi(q)  for all a,b ∈ ℝ

=== PROOF CHAIN ===

STEP 1: State the contraction (with sorry — proved from deep results)
STEP 2: Prove Phi_pos (Phi > 0 for degree ≥ 2 with distinct roots)
STEP 3: Derive Stam from contraction + Phi_pos (Cauchy-Schwarz)

=== LEAN CODE ===

```lean
/-- Phi is strictly positive for real-rooted polynomials with distinct roots. -/
lemma Phi_pos (p : ℝ[X])
    (h_splits : p.Splits (RingHom.id ℝ))
    (h_nodup : p.roots.Nodup)
    (h_deg : p.natDegree ≥ 2) :
    Phi p > 0 := by
  unfold Phi
  -- Phi is a sum of squares. Need to show at least one is nonzero.
  -- For degree ≥ 2, there exist at least 2 distinct roots r₁ ≠ r₂.
  -- The term for r₁ includes 1/(r₁-r₂) ≠ 0.
  sorry

/-- Phi contraction: the heart of the proof.
    Proved via: score identity (Lemma 3.2) + variance identity (Lemma 4.2)
    + positivity from hyperbolicity (Lemma 4.3). -/
lemma phi_contraction (n : ℕ) (hn : n ≥ 2) (a b : ℝ)
    (p q : ℝ[X])
    (hp : p.Splits (RingHom.id ℝ)) (hp_nodup : p.roots.Nodup)
    (hp_monic : p.Monic) (hp_deg : p.natDegree = n)
    (hq : q.Splits (RingHom.id ℝ)) (hq_nodup : q.roots.Nodup)
    (hq_monic : q.Monic) (hq_deg : q.natDegree = n)
    (hpq : (boxplus n p q).Splits (RingHom.id ℝ))
    (hpq_nodup : (boxplus n p q).roots.Nodup) :
    (a + b) ^ 2 * Phi (boxplus n p q) ≤ a ^ 2 * Phi p + b ^ 2 * Phi q := by
  sorry

/-- The Stam inequality follows from contraction by choosing
    a = 1/Phi(p), b = 1/Phi(q) and applying Cauchy-Schwarz arithmetic. -/
theorem finite_free_stam_inequality (n : ℕ) (hn : n ≥ 2)
    (p q : ℝ[X])
    (hp : p.Splits (RingHom.id ℝ)) (hp_nodup : p.roots.Nodup)
    (hp_monic : p.Monic) (hp_deg : p.natDegree = n)
    (hq : q.Splits (RingHom.id ℝ)) (hq_nodup : q.roots.Nodup)
    (hq_monic : q.Monic) (hq_deg : q.natDegree = n)
    (hpq : (boxplus n p q).Splits (RingHom.id ℝ))
    (hpq_nodup : (boxplus n p q).roots.Nodup) :
    invPhi (boxplus n p q) ≥ invPhi p + invPhi q := by
  -- Step 1: Compute roots.card from splits
  have hp_card : p.roots.card = n := by
    rwa [← Polynomial.splits_iff_card_roots.mp hp]
  have hq_card : q.roots.card = n := by
    rwa [← Polynomial.splits_iff_card_roots.mp hq]
  -- Step 2: Get Phi positivity
  have hPp : Phi p > 0 := Phi_pos p hp hp_nodup (by omega)
  have hPq : Phi q > 0 := Phi_pos q hq hq_nodup (by omega)
  -- Step 3: Unfold invPhi
  simp only [invPhi]
  -- Handle the conditional
  have hp_cond : p.roots.Nodup ∧ p.roots.card > 1 := ⟨hp_nodup, by omega⟩
  have hq_cond : q.roots.Nodup ∧ q.roots.card > 1 := ⟨hq_nodup, by omega⟩
  -- Need: (boxplus n p q).roots.card > 1
  -- This follows from splits + natDegree of boxplus
  have hpq_cond : (boxplus n p q).roots.Nodup ∧ (boxplus n p q).roots.card > 1 := by
    constructor
    · exact hpq_nodup
    · sorry -- needs natDegree of boxplus = n and splits
  simp [hp_cond, hq_cond, hpq_cond]
  -- Step 4: Now need 1/Phi(p⊞q) ≥ 1/Phi(p) + 1/Phi(q)
  -- Apply contraction with a = 1/Phi(p), b = 1/Phi(q)
  have hc := phi_contraction n hn (1 / Phi p) (1 / Phi q) p q
    hp hp_nodup hp_monic hp_deg hq hq_nodup hq_monic hq_deg hpq hpq_nodup
  -- hc: (1/Phi(p) + 1/Phi(q))^2 * Phi(p⊞q) ≤ (1/Phi(p))^2 * Phi(p) + (1/Phi(q))^2 * Phi(q)
  -- RHS = 1/Phi(p) + 1/Phi(q) [since (1/x)^2 * x = 1/x]
  have hPpq : Phi (boxplus n p q) > 0 := by
    sorry -- Phi_pos for boxplus
  -- The arithmetic:
  -- Let S = 1/Phi(p) + 1/Phi(q) > 0
  -- S^2 * Phi(p⊞q) ≤ S
  -- S * Phi(p⊞q) ≤ 1
  -- Phi(p⊞q) ≤ 1/S
  -- 1/Phi(p⊞q) ≥ S = 1/Phi(p) + 1/Phi(q)
  have hS : 1 / Phi p + 1 / Phi q > 0 := by positivity
  rw [ge_iff_le, ← sub_nonneg]
  -- field_simp should handle the rest
  field_simp
  -- Use contraction to conclude
  nlinarith [sq_nonneg (1 / Phi p + 1 / Phi q),
             mul_pos hS hPpq,
             div_pos (by positivity : (0:ℝ) < 1) hPp,
             div_pos (by positivity : (0:ℝ) < 1) hPq]
```

=== THE KEY ARITHMETIC IN DETAIL ===

Given: (a+b)²·U ≤ a²·S + b²·T with S,T,U > 0
Want: 1/U ≥ 1/S + 1/T

Set a = 1/S, b = 1/T:
  (1/S + 1/T)² · U ≤ 1/S² · S + 1/T² · T = 1/S + 1/T

Let R = 1/S + 1/T > 0:
  R² · U ≤ R
  R · U ≤ 1  (dividing by R > 0)
  U ≤ 1/R

Since U > 0: 1/U ≥ R = 1/S + 1/T ✓

In Lean, this might look like:
```lean
-- Given h : R^2 * U ≤ R, hR : R > 0, hU : U > 0
-- Conclude: 1/U ≥ R
have h1 : R * U ≤ 1 := by nlinarith
have h2 : U ≤ 1 / R := by rwa [div_le_iff hR] at h1 ⊢; linarith
have h3 : 1 / U ≥ R := by rw [ge_iff_le, le_div_iff hU]; linarith
```
