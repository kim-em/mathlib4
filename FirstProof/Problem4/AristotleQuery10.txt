=== GOAL B (PRIMARY): Prove superadditivity of 1/Phi_4 ===

In cumulant coordinates (k2 = A/12, k3 = B/24, k4 = C/24 - A^2/288):
  A = 12*k2, B = 24*k3, C = 24*k4 + 12*k2^2

1/Phi_4 = -disc / [4*(A^2+12C)*(2A^3-8AC+9B^2)]

The factors in cumulant coordinates:
  A^2 + 12*C = 288*(k2^2 + k4)
  2*A^3 - 8*A*C + 9*B^2 = 576*(4*k2^3 - 4*k2*k4 + 9*k3^2)

Define the feasible domain with sign conditions:

def quartic_cumulant_feasible (k2 k3 k4 : ℝ) : Prop :=
  k2 < 0 ∧
  k2^2 + k4 > 0 ∧
  4*k2^3 - 4*k2*k4 + 9*k3^2 < 0

These ensure denominators are nonzero with consistent sign, allowing cross-multiplication.

STRATEGY: Clear denominators and prove a polynomial inequality.

Let f(a,b,c) = -N(a,b,c) / (6*D(a,b,c)) where
  N(a,b,c) = 16a^6 + 72a^3*b^2 - 48a^2*c^2 + 216a*b^2*c - 81b^4 + 32c^3
  D(a,b,c) = (a^2+c)*(4a^3-4ac+9b^2)

Superadditivity f(a+a',b+b',c+c') >= f(a,b,c) + f(a',b',c') becomes,
after clearing the three negative denominators:
  N_s*D1*D2 - N1*D_s*D2 - N2*D_s*D1 <= 0

This is a polynomial inequality in 6 variables subject to feasibility constraints.
