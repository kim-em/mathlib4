FINITE FREE STAM INEQUALITY — Hyperbolicity and positivity (Lemma 4.3)

=== GOAL ===

Fill the single sorry: finite_free_stam_inequality for ALL n ≥ 2.

=== STRATEGY: POSITIVITY FROM HYPERBOLICITY ===

Reference: Garza-Vargas, Srivastava, Stier (arXiv:2602.15822), Lemma 4.3.

The contraction inequality ||D_Ω(w)||² ≤ ||w||² follows from:

1. VARIANCE IDENTITY (Lemma 4.2):
   ||D_Ω(w)||² = ||w||² − Σᵢ γᵢ · Hᵢ(w,w)
   where Hᵢ is the Hessian of the i-th root map component.

2. POSITIVITY (Lemma 4.3):
   Σᵢ γᵢ · Hᵢ(w,w) ≥ 0
   This follows from convexity of root sums of hyperbolic polynomials.

=== HYPERBOLICITY ARGUMENT ===

Define the multivariate polynomial:
  f_{⊞_n}(x, ζ, η) = (1/n!) Σ_{π ∈ Sₙ} Πᵢ (x - ζᵢ - η_{π(i)})

CLAIM: f_{⊞_n} is hyperbolic in the direction e₁ = (1, 0,..., 0).

PROOF: For any (x₀, ζ, η), the univariate polynomial
  g(t) = f_{⊞_n}(x₀ + t, ζ, η) = (p_ζ ⊞_n p_η)(x₀ + t)
is real-rooted (since boxplus preserves real-rootedness). ∎

By Bauschke-Güler-Lewis-Sendov (Theorem 2.8 in paper, Corollary 3.3 of
bauschke2001hyperbolic):
For a hyperbolic polynomial, if λ₁(ζ) ≥ ... ≥ λₙ(ζ) are the roots,
then Σᵢ cᵢ · λᵢ(ζ) is convex whenever c₁ ≥ ... ≥ cₙ ≥ 0.

Applying this: the roots λᵢ(ζ,η) of g(t) are exactly the roots of p_ζ ⊞_n p_η,
which are Ωᵢ(ζ,η). So Σᵢ cᵢ · Ωᵢ(ζ,η) is convex.

KEY TRICK: Since Σᵢ Ωᵢ = Σᵢ ζᵢ + Σᵢ ηᵢ (mean additivity), we have
Σᵢ Hᵢ = 0 (second derivative of a linear function is zero).
Therefore Σᵢ γᵢ · Hᵢ = Σᵢ (γᵢ + c) · Hᵢ for any constant c.
Choose c = -γₙ ≥ 0 so that γᵢ + c ≥ 0 and γ₁+c ≥ ... ≥ γₙ+c = 0.
By the convexity result, Σᵢ (γᵢ+c) · Hᵢ ≥ 0. ∎

=== ALTERNATIVE: DIRECT CONVEXITY ===

Instead of axiomatizing Bauschke abstractly, we can prove the specific case directly.

The key claim is: for ordered γ₁ ≥ ... ≥ γₙ (roots of p⊞q),
the function F(ζ,η) = Σᵢ γᵢ · Ωᵢ(ζ,η) is convex.

Since Ωᵢ are roots of p_ζ ⊞_n p_η, and boxplus preserves real-rootedness,
we can potentially prove this by:
1. Expressing Ωᵢ via the eigenvalue perturbation theory
2. Using the minimax characterization of ordered eigenvalues
3. Showing convexity via the variational principle
