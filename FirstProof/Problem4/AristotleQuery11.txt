=== PROOF STRATEGY ===

The function f(k2,k3,k4) = -N_cumulant/D_cumulant represents 1/Phi_4.
We need: f(a+a', b+b', c+c') >= f(a,b,c) + f(a',b',c')

CLEARING DENOMINATORS (careful with signs!):
  D_s, D_1, D_2 are all < 0 (by D_cumulant_neg).
  To derive `D_cumulant ≠ 0`, use `ne_of_lt (D_cumulant_neg ...)`.
  Multiplying both sides by D_s * D_1 * D_2 (which is NEGATIVE, since
  product of three negative numbers is negative) REVERSES the inequality:

  f_s >= f_1 + f_2
  <==> N_s * D_1 * D_2 - N_1 * D_s * D_2 - N_2 * D_s * D_1 <= 0

  Call this polynomial P(k2,k3,k4,k2',k3',k4'). We need P <= 0.

KEY DECOMPOSITION (from invPhi_decomposition):
  -N/D = -2/3*k2 + Q/D
  where Q = Q_quartic >= 0 (proven) and D < 0 (proven), so Q/D <= 0.

  The linear part -2/3*k2 is trivially superadditive (equality).
  So superadditivity of -N/D reduces to showing Q/D is SUPERADDITIVE
  (i.e. Q_s/D_s >= Q_1/D_1 + Q_2/D_2, where each term is non-positive).

  NOTE: Q >= 0 and D < 0 give Q/D <= 0 but do NOT imply superadditivity.
  The Q/D superadditivity requires a separate inequality — this is the core difficulty.

STRATEGY 1 — Generalize the Cauchy-Schwarz approach (RECOMMENDED):
  The symmetric case (k3=0) was proven by showing q(x,y) = y^2/(x(x^2+y))
  is subadditive via Cauchy-Schwarz (symmetric_ratio_inequality).

  For the general case, try to express Q/D as a function of suitable variables
  and prove a generalized ratio inequality. The remainder Q_quartic involves
  k3 terms; find substitutions (x = -k2, y = k4, z = 9*k3^2) such that
  Q/D becomes a subadditive function of (x, y, z).

  Bridge lemma approach: prove
    Q_quartic(sum) / D_cumulant(sum) >= Q_quartic(k) / D_cumulant(k) + Q_quartic(k') / D_cumulant(k')
  Then combine with linearity of -2/3*k2.

STRATEGY 2 — Direct polynomial inequality:
  Clear denominators (field_simp), then show P <= 0 using nlinarith with
  auxiliary square terms. P has ~547 terms, degree 15 in 6 variables.
  This is hard for nlinarith alone, but may work with explicit SOS witnesses.

  Hint: When k3=k3'=0, P factors as:
    18432 * (k2^2-k4) * (k2'^2-k4') * ((k2+k2')^2-k4-k4') * (nonneg polynomial)
  All factors are nonneg on the feasible domain (since k4 < k2^2).
  Try decomposing P in powers of k3, k3':
