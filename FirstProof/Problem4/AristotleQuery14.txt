=== KEY INSIGHT FOR CUMULANT ADDITIVITY ===

The boxplus coefficient formula is:
  (p ⊞_n q).coeff(n-k) = sum_{i+j=k} [C(n-i,n-k)*C(n-j,n-k)/C(n,n-k)] * p.coeff(n-i) * q.coeff(n-j)

For CENTERED polynomials (coeff(n) = 1, coeff(n-1) = 0):
When k >= 2, the only nonzero terms in the sum have i >= 2 or j >= 2
(because coeff(n-1) = 0 forces i=0 when j=k, giving coeff(n)=1, etc.)

Actually the key simplification: for centered polys, the sum reduces to
  (p ⊞_n q).coeff(n-k) = p.coeff(n-k) + q.coeff(n-k)
because the cross terms (i >= 1, j >= 1) involve coeff(n-1) = 0.

More precisely: the i=0,j=k term gives [C(n,n-k)*C(n-k,n-k)/C(n,n-k)] * 1 * q.coeff(n-k)
= q.coeff(n-k). Similarly the i=k,j=0 term gives p.coeff(n-k).
For 1 <= i <= k-1: we need j = k-i >= 1, so we use p.coeff(n-i) and q.coeff(n-j).
But if i=1 or j=1, we get coeff(n-1) = 0. If i >= 2 AND j >= 2,
then i + j = k >= 4. So for k <= 3, all cross terms vanish.

For k >= 4: cross terms with i >= 2, j >= 2 can be nonzero!
So coefficient additivity does NOT hold for k >= 4 in general.
Instead, CUMULANT additivity holds, where cumulants are nonlinear functions
of the coefficients.

The cumulant kappa_k is defined by the relation:
  a_k = sum over partitions of k of products of kappa's / combinatorial factors

For k=2: kappa_2 = a_2/C(n,2) = a_2 * 2/(n(n-1))
For k=3: kappa_3 = a_3/C(n,3)
For k=4: kappa_4 = a_4/C(n,4) - kappa_2^2 * C(n,2)^2 / (2*C(n,4))
   (the correction is because the partition {2,2} of 4 contributes)

The context has boxplus_centered_deg4_kappa4_additive which proves kappa_4 additivity.

IMPORTANT: Even if general cumulant additivity is hard, proving it for k=2,3 (which
IS just coefficient additivity for centered polys) is a great start. It's already
done in the context! The challenge is k >= 4.
