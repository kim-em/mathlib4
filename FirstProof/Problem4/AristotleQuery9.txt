=== NEW RESULT: EXPLICIT Phi_4 FORMULA (verified by CAS) ===

THIS IS THE KEY NEW INFORMATION. We have computed the explicit closed-form formula for
Phi_4 of a general centered quartic. This formula has been verified numerically against
exact rational root computations for 84 distinct quartics, with zero errors.

For a centered quartic p(x) = x^4 + A*x^2 + B*x + C with 4 distinct real roots:

  Phi_4(A,B,C) = -4 * (A^2 + 12*C) * (2*A^3 - 8*A*C + 9*B^2) / disc(A,B,C)

where disc(A,B,C) is the polynomial discriminant:

  disc(A,B,C) = 256*C^3 - 128*A^2*C^2 + 144*A*B^2*C - 27*B^4 + 16*A^4*C - 4*A^3*B^2

Equivalently, since 1/Phi is what we need for the inequality:

  1/Phi_4(A,B,C) = -disc(A,B,C) / [4 * (A^2 + 12*C) * (2*A^3 - 8*A*C + 9*B^2)]

Verification for the symmetric case (B=0):
  disc(A,0,C) = 16*C*(A^2 - 4*C)^2
  Phi_4(A,0,C) = -4*(A^2+12C)*2A*(A^2-4C) / [16*C*(A^2-4C)^2]
              = -A*(A^2+12C) / [2*C*(A^2-4C)]
              = A*(A^2+12C) / [2*C*(4*C-A^2)]
  This matches the proven Phi_symmetric_quartic.

Key factorizations:
  Phi_4 * disc = -4*(A^2 + 12*C)*(2*A^3 - 8*A*C + 9*B^2)
  This is a polynomial of degree 5 (weighted degree 10).

=== CUMULANT COORDINATES ===

With kappa_2 = A/12, kappa_3 = B/24, kappa_4 = C/24 - A^2/288
(equivalently: A = 12*k2, B = 24*k3, C = 24*k4 + 12*k2^2):

  A^2 + 12*C = 288*(k2^2 + k4)

which matches the proven invPhi_symmetric_quartic_expansion:

=== GOAL A (PRIMARY): Prove the Phi_4 formula ===

theorem Phi_quartic_general (A B C : R) (r : Fin 4 -> R)
    (hr_distinct : Function.Injective r)
    (hr_sum : r 0 + r 1 + r 2 + r 3 = 0)
    (hr_roots : forall i, r i ^ 4 + A * r i ^ 2 + B * r i + C = 0) :
    let disc := 256 * C ^ 3 - 128 * A ^ 2 * C ^ 2 + 144 * A * B ^ 2 * C
                - 27 * B ^ 4 + 16 * A ^ 4 * C - 4 * A ^ 3 * B ^ 2
    phi 4 r = -4 * (A ^ 2 + 12 * C) * (2 * A ^ 3 - 8 * A * C + 9 * B ^ 2) / disc

PROOF STRATEGY for the Phi formula:

Method 1 (direct): Use phi = sum_i (sum_{j!=i} 1/(r_i-r_j))^2. Cross-multiply by disc
= prod_{i<j}(r_i-r_j)^2 to clear denominators. The identity then becomes:

  sum_i (sum_{j!=i} 1/(r_i-r_j))^2 * prod_{i<j}(r_i-r_j)^2
  = -4 * (A^2+12C) * (2A^3-8AC+9B^2)

Both sides are symmetric polynomials in the roots (weight 10). Express in terms of
the power sums s_k = sum r_i^k using:
  s_0=4, s_1=0, s_2=-2A, s_3=-3B, s_4=2A^2-4C

This reduces to a polynomial identity that can be verified by `ring` or `nlinarith`.

Method 2 (factored): The LHS can be rewritten. For each i:
  sum_{j!=i} 1/(r_i-r_j) = p''(r_i)/(2*p'(r_i)) where p'(r_i) = prod_{j!=i}(r_i-r_j)

So Phi * disc = Phi * prod_{i<j}(r_i-r_j)^2
  = sum_i [p''(r_i)/(2*p'(r_i))]^2 * prod_{i<j}(r_i-r_j)^2

For each term i in the sum: [p''(r_i)]^2/(4*p'(r_i)^2) * prod_{i<j}(r_i-r_j)^2
  = [p''(r_i)]^2/4 * prod_{j!=i}(r_j-r_k)^2 for k<j, both != i
  (because prod_{i<j}(r_i-r_j)^2 / p'(r_i)^2 = prod_{j<k, j,k!=i}(r_j-r_k)^2)

So Phi*disc = (1/4) * sum_i p''(r_i)^2 * D_i where D_i = prod_{j<k, j,k!=i}(r_j-r_k)^2.

With p''(r_i) = 12*r_i^2 + 2A, and D_i being the discriminant of the cubic
with roots {r_j : j!=i}, this may be easier to manipulate.

Step 1: Define the feasible domain with SIGN LEMMAS.

def quartic_cumulant_feasible (k2 k3 k4 : R) : Prop :=
  k2 < 0 /\                             -- second cumulant is negative for real-rooted quartics
  k2 ^ 2 + k4 > 0 /\                    -- ensures A^2+12C > 0 (positive factor)
  4 * k2 ^ 3 - 4 * k2 * k4 + 9 * k3 ^ 2 < 0  -- ensures 2A^3-8AC+9B^2 < 0 (sign)

These sign conditions are critical: they ensure the denominators of 1/Phi_4 are nonzero
and have consistent sign, allowing us to cross-multiply the inequality.

Step 2: Cross-multiply to get a polynomial inequality.

The superadditivity f(a+a', b+b', c+c') >= f(a,b,c) + f(a',b',c') where
  f(a,b,c) = -N(a,b,c) / (6 * D(a,b,c))
  N(a,b,c) = 16a^6 + 72a^3*b^2 - 48a^2*c^2 + 216a*b^2*c - 81b^4 + 32c^3
  D(a,b,c) = (a^2+c)*(4a^3-4ac+9b^2)

After clearing the three (negative) denominators and flipping the sign, becomes:
  N_s*D1*D2 <= N1*D_s*D2 + N2*D_s*D1
where subscripts s,1,2 denote evaluation at sum, first, second cumulants.

Rearranging: N_s*D1*D2 - N1*D_s*D2 - N2*D_s*D1 <= 0

This is a polynomial inequality in 6 variables (k2,k3,k4,k2',k3',k4')
subject to the feasible domain constraints.

def quartic_has_distinct_roots (A B C : R) : Prop :=
  exists r : Fin 4 -> R, Function.Injective r /\
    r 0 + r 1 + r 2 + r 3 = 0 /\
    forall i, r i ^ 4 + A * r i ^ 2 + B * r i + C = 0
