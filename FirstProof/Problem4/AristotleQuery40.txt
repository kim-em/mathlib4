FINITE FREE STAM INEQUALITY — Direct nlinarith proof of f_aux weighted inequality

=== GOAL ===

Prove the single sorry: finite_free_stam_inequality for all n ≥ 2.
  invPhi (boxplus n p q) ≥ invPhi p + invPhi q

=== THE KEY ALGEBRAIC INEQUALITY ===

For symmetric quartics, the entire proof reduces to:

THEOREM (invPhi_sym_quartic_superadditive):
For t ∈ (0,1), x ∈ (0,1/4), y ∈ (0,1/4):
  f_aux(t²x + (1-t)²y + t(1-t)/6) ≥ t·f_aux(x) + (1-t)·f_aux(y)

where f_aux(k) = 2k(1-4k)/(12k+1).

PROOF STRATEGY: Clear denominators and prove the resulting polynomial inequality.

Let Z = t²x + (1-t)²y + t(1-t)/6. All denominators are positive:
  12x + 1 > 0 (since x > 0)
  12y + 1 > 0 (since y > 0)
  12Z + 1 > 0 (since Z > 0)

After clearing denominators, we need to show:

  2Z(1-4Z)(12x+1)(12y+1) ≥ t·2x(1-4x)(12Z+1)(12y+1) + (1-t)·2y(1-4y)(12Z+1)(12x+1)

Equivalently:
  2Z(1-4Z)(12x+1)(12y+1) - t·2x(1-4x)(12Z+1)(12y+1) - (1-t)·2y(1-4y)(12Z+1)(12x+1) ≥ 0

This is a POLYNOMIAL in t, x, y (after substituting Z = t²x + (1-t)²y + t(1-t)/6).

    (hx0 : 0 < x) (hx1 : x < 1/4)
    (hy0 : 0 < y) (hy1 : y < 1/4) :
    f_aux (t^2 * x + (1-t)^2 * y + t*(1-t)/6) ≥ t * f_aux x + (1-t) * f_aux y := by
  unfold f_aux
  rw [ge_iff_le, div_add_div _ _ (ne_of_gt (by nlinarith)) (ne_of_gt (by nlinarith))]
  rw [div_le_div_iff (by nlinarith) (by nlinarith)]

  nlinarith [sq_nonneg (x - y), sq_nonneg t, sq_nonneg (1 - t),

             sq_nonneg ((1-t)*(1-4*y)),
             mul_pos ht0 (sub_pos.2 ht1),
             mul_pos hx0 hy0,
