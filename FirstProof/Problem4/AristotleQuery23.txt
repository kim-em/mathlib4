DERIVATIVE REDUCTION IDEA:
If p has degree n with roots λ₁,...,λₙ, then p' has degree n-1 with roots
μ₁,...,μ_{n-1} that interlace the λᵢ (by Rolle's theorem).

The Gauss-Lucas theorem says roots of p' lie in the convex hull of roots of p.

Question: Does Phi(p) relate to Phi(p') in a useful way?

From Phi_derivative_form: Phi(p) = Σᵢ (p''(λᵢ)/(2p'(λᵢ)))²

Note that p''(λᵢ)/(2p'(λᵢ)) can be seen as a "logarithmic derivative correction":
  d/dx [log p'(x)] |_{x=λᵢ} = p''(λᵢ)/p'(λᵢ)

So Phi(p) = (1/4) Σᵢ [d/dx log p'(x)]²|_{x=λᵢ}

APPROACH B: Electrostatic / convexity argument.

Define E(p) = Σᵢ Σ_{j≠i} 1/(λᵢ - λⱼ)² = "electrostatic energy" of the roots.

Note: E(p) ≠ Phi(p) in general. We have:
  Phi(p) = Σᵢ (Σ_{j≠i} 1/(λᵢ-λⱼ))² = Σᵢ Sᵢ²
  E(p) = Σᵢ Σ_{j≠i} 1/(λᵢ-λⱼ)² = Σᵢ Tᵢ where Tᵢ = Σ_{j≠i} 1/(λᵢ-λⱼ)²

By Cauchy-Schwarz: Sᵢ² ≤ (n-1)Tᵢ, so Phi ≤ (n-1)E.
By (Σ Sᵢ)² = 0 ≤ n·Σ Sᵢ² = n·Phi, this is consistent.

If we could show E(p⊞q) ≤ E(p) + E(q) (subadditivity of energy),
then combined with Phi ≤ (n-1)E, we'd get SOME bound, but not the sharp one.
